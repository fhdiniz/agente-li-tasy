# TECH_ONE-Integrations

### Brief Introduction

This interface is to send patient demographic to ECG devices and receive ecg image report.
Messages for this interface :-

1. Outbound  ADT-01 HL7 message from Tasy to Philips TC50 ECG  when patient is admitted.
2. Outbound  ADT-02 HL7 message from Tasy to Philips TC50 ECG  when patient is transfered.
3. Outbound  ADT-03 HL7 message from Tasy to Philips TC50 ECG  when patient is discharged.
4. Outbound  ORM-001 HL7 message from Tasy to  Philips TC50 ECG.
5. Receive Inbound  ORU – R01 HL7 message from  Philips TC50 ECG  to Tasy for ECG Exams.
