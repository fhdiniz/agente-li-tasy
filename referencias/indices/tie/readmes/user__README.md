# User

Allows the creation, activation, deactivation, blocking, creation of profile for the user, deletion of profile for the user, searching of user data and profile data in Tasy.

<br>

- Available endpoints
   - Search user and user data
   - Search user's profile
   - Create user
   - Activate user
   - Deactivate user
   - Block user
   - Create profile for the user
   - Delete profile for the user
