# Pix Integration

Integration with the Itau, Santander and Banco do Brasil in REST, using the BACEN manual and the HTTPS protocol.

The integration is about the immediate billing to receive in the Tasy function Treasury.

This Integration is only for Brasil,and it has the following features.

- Create a new immediate billing with Pix;

- Generate a Pix QR-Code;

- Receive the Pix;

- Payment return of the pix;
