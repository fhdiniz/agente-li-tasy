# Account Batch

Allows for the creation, deletion and search of accounting batches and accounting movements in Tasy by a third party.

<br>

- Available endpoints
   - Search accounting batches (any batch)
   - Create accounting batches, accounting movements and apportionment by cost center (generated in Tasy with type "Typing" and origin "TIE")
   - Undo accounting batches (only batches generated with a "TIE" origin)
   - Delete accounting batches (only batches generated with a "TIE" origin)
