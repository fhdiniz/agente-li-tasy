# connector

The Laboratory has only one connector that receives HL7 ORU_R01. Microbiology has three connectors that receive HL7 ORU_R01, each for a different sample.

- [Laboratory](connector_lab.bft)
   - API Laboratory - eCM (MLLP)
- [Microbiology](connectors_mic.bft)
   - API Microbiology Sample 2 - eCM (MLLP)
   - API Microbiology Sample 3 - eCM (MLLP)
   - API Microbiology Sample 4 - eCM (MLLP)
