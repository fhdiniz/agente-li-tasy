### SONIC LIS

Integration with SONIC LIS system.  
Uses HL7 v2.4 with MLLP Protocol for sending and receiving HL7 Messages

1. Laboratory Order request
2. Laboratory Order update
3. Laboratory Report ack
4. Patient admission
5. Patient transfer
6. Patient discharge


Tasy receives following messages from LIS system

1. Laboratory Report result
2. Laboratory Order update
