# ANMAT-Transaction Integrations

### Brief Introduction


This interface is used to make performed Transaction queries to ANMAT by using following soap operations:-

-> Medicine All Transactions :-  "getTransaccionesWS"

-> Unconfirmed Medicines :- "getTransaccionesNoConfirmadas"

-> Medical Product All Transaction :- "getTransaccionesWS"


Definitions:-

-> Medicine All Transactions :- Bring the list of all medicine transaction based on the query performed by the user and record the response.
-> Unconfirmed Medicines :- Brings a list of transactions where the agent is the destination and are not confirmed by the receiving agent.
-> Medical Product All Transaction :- Bring the list of all medical product transaction based on the query performed by the user and record the response.
