### Nurse Call

Integration with Nurse Call system.

General Specifications 
 
Standard Interface Specifications: 
 
Connectivity Network – TCP/IP 
Protocol - XML 
Socket Connection - Local Alarm Solution (LAS) will be the TCP Client, connecting to the third party (TCP Host) TCP Host should be set as ‘Always Connected’ 
Data Direction - XML data will be sent from LAS (TCP Client) to Third-party (TCP Host).  TCP Host is not required to send any data back to TCP Client.
Host IP Address - To be defined by Third-party vendor 
Host Port - 1024 


Tasy receives following message from Nurse Call system

1. Nurse call details
2. Nurse attend details
