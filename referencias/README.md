# Referências

Material de entrada do agente. Swaggers, índices e LIs de referência são material interno da Philips e **são versionados** (ver [decisão 0006](../docs/decisoes/0006-referencias-versionadas.md)). Documentos de terceiros **não** são versionados.

| Pasta | Conteúdo |
|---|---|
| `openapi/` | Um arquivo Swagger/OpenAPI por API do Tasy (JSON) |
| `indices/` | Índices extraídos do código-fonte do Tasy (PL/SQL, tasy-interfaces) e do catálogo TIE. Ver [indices/README.md](indices/README.md) |
| `lis-referencia/` | Template oficial e LIs existentes usadas como modelo (`modelo-antigo/`: LIs com layout Philips, só referência de conteúdo) |
| `cci-referencia/` | Template e exemplos de CCI (controle de mudança) — fase 2 |
| `manuais-referencia/` | Template e exemplos de manuais (integração, operação) — fase 2 |
| `documentos-terceiros/` | Documentos de entrada dos terceiros (ex.: Evya 4uHub) — fora do Git |
