# 0005 — Repositório inicial na conta do Fernando

**Status:** Aceita

## Contexto
O projeto precisa começar sem depender da criação de repositório na organização da empresa.

## Decisão
O repositório nasce privado na conta GitHub do Fernando e será migrado depois para a organização da empresa.

## Consequências
- Início imediato do desenvolvimento.
- O repositório deve permanecer **privado**, pois contém material interno da Philips (ver 0006).
- A migração deve preservar o histórico (transferência de repositório no GitHub).
- Os manifestos e o marketplace dos plugins devem evitar URLs fixas da conta pessoal, para facilitar a migração.
